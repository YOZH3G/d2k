# D2K — Dynamic2Keenetic

D2K снимает блокировки на роутере. Он смотрит живой трафик, измеряет
подозрительные соединения, подбирает обход и запоминает его.

Начального списка заблокированных сайтов нет. D2K ничего не знает заранее и
находит всё сам, замером.

Весь runtime написан на C. Zapret и nfqws не используются. Поддержаны TLS 1.2,
TLS 1.3, QUIC, открытый HTTP, голос Discord, IPv4 и IPv6.

> Проект предназначен для исследования сетевых протоколов и изучения работы
> систем анализа трафика. Используйте его только в учебных целях.

**Это MVP.** Он проверен в поле на ARM64-роутере Keenetic. Другие модели
требуют проверки. Раздел [Что проверено](#что-проверено) говорит прямо, где
проверка есть, а где её нет.

## Установка

Одна команда. Она же обновляет уже поставленный D2K.

### Keenetic

Выполните команду в SSH-терминале Entware от пользователя root.

Не выполняйте её на компьютере. Не выполняйте её в командной строке
KeeneticOS.

```sh
(f=$(mktemp) && curl -fsSL --connect-timeout 10 --max-time 120 https://raw.githubusercontent.com/necronicle/d2k/main/scripts/install.sh -o "$f" && D2K_REF=main sh "$f"; r=$?; rm -f "$f"; exit "$r")
```

### OpenWrt

D2K работает на OpenWrt 22.03 и новее. Entware для этого не нужен.

Выполните команду в SSH роутера от пользователя root. В образе OpenWrt нет
`curl`, поэтому команда использует `wget`.

```sh
(f=$(mktemp) && wget -q -T 120 -O "$f" https://raw.githubusercontent.com/necronicle/d2k/main/scripts/install.sh && D2K_REF=main sh "$f"; r=$?; rm -f "$f"; exit "$r")
```

### Что делает установщик

1. Определяет архитектуру по Entware и `uname`.
2. Проверяет зависимости, NFQUEUE, connbytes и свободное место.
3. Ставит комплект и запускает службу.

Установщик проверяет всё это **до** того, как изменит работающую установку.
Неполный комплект он не ставит.

Устанавливается ветка `main`. Команду достаточно выполнить один раз: дальше
D2K обновляет себя сам. Перед запуском вы можете
[прочитать код установщика](scripts/install.sh).

## Перед первой установкой

### Keenetic

1. Установите Entware.
2. Включите компонент KeeneticOS **«Модули ядра подсистемы Netfilter»**.
3. Подключитесь к Entware по SSH.
4. Поставьте зависимости одной командой:

   ```sh
   opkg update && opkg install curl ca-bundle iptables ipset kmod_ndms xtables-addons_legacy openssl-util
   ```

5. Остановите z2k, Zapret и другие программы, которые меняют тот же трафик.

Команды `ip` и `start-stop-daemon` должны быть доступны в Entware.

[Инструкция Entware](https://support.keenetic.com/hero-5g/kn-4110/en/20980-installing-the-entware-repository-on-a-usb-drive.html)
написана для ARM64-модели. Выберите на сайте свою модель.

Свою архитектуру вы увидите командами `uname -m` и `opkg print-architecture`.

### OpenWrt

Недостающие пакеты установщик ставит сам. Он использует `apk` в OpenWrt 25.12
и `opkg` в 24.10. Нужен доступ в интернет.

**Место.** Роутеру нужно:

| Где | Сколько | Зачем |
| --- | --- | --- |
| файловая система с `/opt` | 21 МиБ | пакеты (~7 МБ) и файлы D2K (~14 МиБ) |
| `/tmp` | 8,5 МиБ | комплект скачивается целиком до изменений |

`/tmp` на OpenWrt — это tmpfs, то есть оперативная память.

**Роутеру с 8 или 16 МиБ флеша этого места не хватит.** Поставьте USB-накопитель
и разместите на нём `/opt`. После установки D2K с пакетами занимает около
15 МБ.

Установщик проверяет `/opt` и `/tmp` до любых изменений. Он печатает, сколько
места нужно и сколько есть.

## После установки

D2K запускается сам в активном режиме (`MODE=apply`).

Он подбирает обходы по живому трафику. Первый поиск по новому сайту занимает
время: движок сначала измеряет, и только потом ставит обход.

**Рабочий трафик поиск не запускает.** Подозрение — это не блокировка.

### Семейства доменов

D2K объединяет домены в семейства по своим подтверждённым обходам.

Новое имя семейства получает обход сразу, без отдельного поиска. TLS 1.2,
TLS 1.3, QUIC, ECH, IPv4 и IPv6 при этом не смешиваются. Узел, который
действительно отличается, получает своё точечное решение.

[Проверка на роутере](docs/field/2026-10-01-learned-domain-families.md).

## Панель

Панель открывается **на роутере**: `http://<адрес-роутера>:8090/`.

Обычно это **http://192.168.1.1:8090/**. Точный адрес печатает установщик.

Панель показывает ход замера: число зондов, текущий вопрос коробке и
найденные обходы. В ней есть кнопки управления движком и Telegram-туннелем.

**У панели нет пароля.** Доступ доверен локальной сети. Не открывайте порт
8090 в интернет.

## Обновления

Новые версии выходят подписанными выпусками на GitHub.

Роутер проверяет подпись закреплённым ключом. Если подпись не сошлась, роутер
не ставит ничего.

Порядок установки выпуска:

1. Роутер ставит выпуск ночью, между 03:00 и 05:00 по своему времени. Кнопка
   «Установить сейчас» в разделе «Обновления» ставит его сразу.
2. Роутер сохраняет прежнюю версию до установки.
3. Через минуту после установки роутер проверяет, что движок, контроллер и
   панель работают.
4. Проверка прошла — остаётся только новая версия. Проверка не прошла —
   роутер возвращает прежнюю версию и помечает выпуск плохим.

Конфигурация и подобранное переживают обновление.

Ночную установку выключает тумблер в панели. Тогда роутер ночью только
проверяет наличие выпуска.

Журнал обновлений — `/opt/d2k/log/update.log`.

## Удаление

Keenetic:

```sh
(f=$(mktemp) && curl -fsSL --connect-timeout 10 --max-time 120 https://raw.githubusercontent.com/necronicle/d2k/main/scripts/uninstall.sh -o "$f" && sh "$f"; r=$?; rm -f "$f"; exit "$r")
```

OpenWrt:

```sh
(f=$(mktemp) && wget -q -T 120 -O "$f" https://raw.githubusercontent.com/necronicle/d2k/main/scripts/uninstall.sh && sh "$f"; r=$?; rm -f "$f"; exit "$r")
```

Удаление снимает службы, панель, правила D2K, его DNS-записи Instagram,
конфигурацию, подобранное и ключ Telegram.

**Подобранное будет потеряно.** Чужие правила и DNS-записи удаление не
трогает.

Чтобы оставить конфигурацию и подобранное, добавьте `D2K_KEEP_STATE=1` перед
`sh "$f"`.

На OpenWrt удаление не снимает поставленные пакеты: ими могут пользоваться
другие программы.

[Код удаления](scripts/uninstall.sh).

## Управление

### Команды службы

```sh
/opt/etc/init.d/S99d2k status       # состояние компонентов
/opt/etc/init.d/S99d2k stop         # остановить D2K и снять его правила
/opt/etc/init.d/S99d2k start        # запустить снова
/opt/etc/init.d/S99d2k restart      # перезапустить
/opt/etc/init.d/S99d2k clear-found  # стереть подобранное
```

Если после установки появились проблемы с сетью, выполните `stop` первым
делом.

Настройки лежат в `/opt/d2k/config`. Журналы лежат в `/opt/d2k/log/`.

### Как стереть подобранное

Нажмите в панели **«Очистить подобранное»**. Панель спросит подтверждение и
назовёт, что именно исчезнет.

Та же работа из командной строки — `S99d2k clear-found`.

**Восстановить подобранное нельзя.** Подбор начнётся с нуля, и каждый сайт
придётся пройти заново.

Подобранное лежит в `/opt/d2k/state/`:

| Файл | Что в нём |
| --- | --- |
| `catalog.json` | коробки и найденные обходы TLS, QUIC и голоса |
| `http-plans.txt` | обходы открытого HTTP для имён без HTTPS |
| `https-cache.txt` | проверка HTTPS имён, которым провайдер подменял ответ |

Движок останавливается на время очистки. Контроллер держит каталог в памяти,
поэтому удалить файл под работающим контроллером нельзя: каталог вернётся.

## Instagram и WhatsApp

Роутер получает свежие адреса от собственного C-резолвера D2K на VPS.

Он проверяет диапазоны Meta, доступность узла и его сертификат. Только после
этого роутер сохраняет свои DNS-записи, по 1–2 адреса на имя.

Порядок обновления:

1. Первое обновление идёт в фоне сразу после установки.
2. Дальше роутер обновляет записи ежедневно, между 01:00 и 04:59 по своему
   времени. Минута у каждой установки своя.
3. Неудача повторяется через 30 минут, час, два часа — но не позже
   следующего дня.
4. Прежние записи при неудаче сохраняются.

Каждую свою запись роутер ежедневно проверяет сам. Недоступную запись он
снимает, и имя снова решается обычным DNS.

Блокировка имени не считается неисправностью адреса. Обход SNI движок
подбирает отдельно.

```sh
/opt/d2k/d2k-instagram-dns.sh refresh        # обновить сейчас
cat /opt/d2k/state/instagram-ip-hosts.tsv    # записи, принадлежащие D2K
tail -n 30 /opt/d2k/log/instagram-dns.log    # журнал
```

Ошибка обновления не означает, что VPS недоступен. Журнал различает отказ
запроса, недоверенный адрес или сертификат и ошибку сохранения на роутере.

Не отключайте проверку сертификатов ради успешного статуса.

## Telegram-туннель

Туннель включается сам. Роутер создаёт собственный ключ и регистрируется на
relay по HTTPS.

Общий секрет вводить не нужно. Приватный ключ не покидает роутер.

Туннель ведёт только TCP Telegram. Весь остальной трафик идёт как обычно.

Ручное отключение туннеля переживает обновление.

## Архитектуры

Для каждой цели собирается полный статический комплект на C: движок,
контроллер, панель и Telegram.

Отдельно ставить библиотеки OpenSSL не нужно. Пакет `openssl-util` и
CA-сертификаты нужны только установочным скриптам.

| Цель | Требования |
| --- | --- |
| ARM64 | AArch64 |
| ARM32 | ARMv7 и новее, little-endian, EABI, VFPv3 |
| MIPS / MIPSEL | MIPS32, big-endian или little-endian, soft-float |
| MIPS64EL | MIPS64, little-endian, N64 ABI, **нужен FPU** |
| x86 / x86-64 | i686 / x86-64 |
| PPC64 | 64-битный PowerPC, big-endian |
| RISC-V64 | RV64GC |

Для MIPS64EL установщик проверяет наличие FPU. Без подтверждённого FPU он
отказывается менять установку.

Не поддержаны: Lexra, ARMv5, ARMv6, 32-битный PPC и MIPS64EL без FPU.

MIPS64 с 32-битным Entware получает пакет MIPSEL или MIPS по ABI Entware.
Неизвестная архитектура вызывает отказ до остановки старой службы.

## Что проверено

Этот раздел говорит, где проверка есть, а где её нет. Пакеты тестовые, и
совместимости со всеми моделями они не подтверждают.

**Проверено в поле.** ARM64-роутер Keenetic: 19 сайтов в Safari и Chrome с
записью трафика, HTTP/3, WhatsApp Web, приложение Discord, IPv6 на Android.

**Проверено в лаборатории.** Полный набор модульных тестов и кросс-сборок.
Запуск всех 36 бинарников под QEMU. Правила файрвола настоящим iptables.
Сценарии установки, обновления и удаления в изолированном контейнере.
MIPS32-сессии на эмулируемом CPU без FPU. Чистые OpenWrt 24.10.8 и 25.12.5 в
QEMU.

**Не проверено.** Настоящий роутер с OpenWrt — отзывы нужны. Все модели,
кроме ARM64 Keenetic. Эмуляция проверяет запуск и переносимость, но не
драйверы Netfilter, не NDM и не производительность конкретного роутера.

История изменений по датам, с полевыми замерами и границами каждой
проверки: [CHANGELOG.md](CHANGELOG.md).

## Для разработчиков

D2K вырос из переноса «Поиска по домену» z2k на C. С 03.10.2026 он
развивается как самостоятельный проект. Мерило изменений — полевые замеры, а
не совпадение с донором.

Требования: [D2K_SPEC.md](D2K_SPEC.md) — начните с §0.
История и ограничения: [D2K_HANDOFF.md](D2K_HANDOFF.md).

Принятый владельцем MVP не означает, что выполнены все пункты полного ТЗ.

### Проверки

```sh
sh scripts/check.sh
make -C telegram test
make -C panel test
make -C relay-enroll test
sh scripts/lab-install.sh   # изолированная установка и удаление; нужен Docker
```

### Сборка

Нужны make, Perl, git и Zig **0.16.0**. Для MIPS64EL нужен Zig **0.14.1**:
версия 0.16.0 не линкует полный runtime этой цели. OpenSSL закреплён по
коммиту.

```sh
ZIG_MIPS64EL=/path/to/zig-0.14.1 sh scripts/build-router.sh
ARCHES="arm64 mipsel" sh scripts/build-router.sh          # только нужные пакеты
ZIG_MIPS64EL=/path/to/zig-0.14.1 sh scripts/build-router-tests.sh
sh scripts/check-router-builds.sh                          # Linux, qemu-user, binutils
```

### Процессы

На роутере работают четыре процесса на C: `d2kd`, `d2kc`, `d2kpanel` и
`d2ktg`.

Серверный relay Telegram — внешний сервис z2k. Его Go-runtime на роутер не
ставится. Регистрация роутеров и резолвер Instagram — собственный C-сервис
D2K на VPS ([relay-enroll](relay-enroll)).

### Выпуск

Порядок, правила и действия при сбоях: [RELEASING.md](RELEASING.md).

Выпуск — это один запуск GitHub Actions на ветке `main`. Workflow собирает
девять арок, проверяет их под QEMU, пакует архив на каждую арку и подписывает
`latest.json`.

Закрытый ключ подписи в репозиторий не попадает. Открытый ключ закреплён в
`files/d2k-update.sh`.
