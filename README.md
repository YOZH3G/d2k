# D2K — Dynamic2Keenetic

D2K работает на роутере и снимает блокировки сайтов.

D2K смотрит трафик. D2K измеряет соединение, которое не работает. D2K
подбирает обход и запоминает его.

D2K не использует список заблокированных сайтов. D2K находит каждый обход
сам.

> Проект предназначен для исследования сетевых протоколов и изучения работы
> систем анализа трафика. Используйте его только в учебных целях.

## Что умеет D2K

D2K работает с этими протоколами:

- TLS 1.2 и TLS 1.3;
- QUIC (HTTP/3);
- открытый HTTP;
- голос Discord;
- IPv4 и IPv6.

Весь код D2K написан на C. D2K не использует Zapret и nfqws.

**Состояние.** D2K — это MVP. Полевая проверка сделана на ARM64-роутере
Keenetic. Другие модели проверки не прошли. Подробно — в разделе
[Что проверено](#что-проверено).

## Что нужно

### Keenetic

| Что | Где взять |
| --- | --- |
| Entware | [инструкция Keenetic](https://support.keenetic.com/hero-5g/kn-4110/en/20980-installing-the-entware-repository-on-a-usb-drive.html) |
| Компонент «Модули ядра подсистемы Netfilter» | настройки KeeneticOS |
| Доступ по SSH к Entware от root | адрес, порт и пароль Entware |
| Доступ к GitHub | интернет на роутере |

Инструкция Entware написана для ARM64-модели. На сайте выберите свою модель.

### OpenWrt

| Что | Значение |
| --- | --- |
| Версия | OpenWrt 22.03 и новее |
| Entware | не нужен |
| Место в файловой системе с `/opt` | 21 МиБ |
| Место в `/tmp` | 17,2 МиБ |
| Доступ по SSH от root | нужен |
| Доступ к интернету | нужен |

`/tmp` на OpenWrt находится в оперативной памяти.

**Роутеру с 8 или 16 МиБ флеша места не хватит.** Подключите USB-накопитель.
Разместите на нём `/opt`.

## Подготовка

Сделайте подготовку до установки. Установщик проверяет всё это сам. Если
чего-то нет, установщик останавливается и ничего не меняет.

### Keenetic

1. Установите Entware.
2. Включите компонент KeeneticOS «Модули ядра подсистемы Netfilter».
3. Подключитесь к Entware по SSH от пользователя root.
4. Установите пакеты:

   ```sh
   opkg update && opkg install curl ca-bundle iptables ipset kmod_ndms xtables-addons_legacy openssl-util
   ```

5. Остановите z2k, Zapret и другие программы, которые меняют тот же трафик.

**ВНИМАНИЕ:** Не запускайте D2K вместе с z2k или Zapret. Две программы на
одном трафике мешают друг другу.

Архитектуру роутера покажут команды `uname -m` и `opkg print-architecture`.

### OpenWrt

1. Подключитесь к роутеру по SSH от пользователя root.
2. Проверьте свободное место: `df -h /opt /tmp`.
3. Если места мало, подключите USB-накопитель и разместите на нём `/opt`.

Пакеты для OpenWrt ставит установщик. Он использует `apk` в OpenWrt 25.12 и
`opkg` в OpenWrt 24.10.

## Установка

**ВНИМАНИЕ:** Выполняйте команду на роутере. Не выполняйте её на компьютере.
На Keenetic не выполняйте её в командной строке KeeneticOS.

### Keenetic

Выполните команду в SSH-терминале Entware:

```sh
(f=$(mktemp) && curl -fsSL --connect-timeout 10 --max-time 120 https://raw.githubusercontent.com/necronicle/d2k/main/scripts/install.sh -o "$f" && D2K_REF=main sh "$f"; r=$?; rm -f "$f"; exit "$r")
```

### OpenWrt

В OpenWrt нет `curl`. Команда использует `wget`.

Выполните команду в SSH-терминале роутера:

```sh
(f=$(mktemp) && wget -q -T 120 -O "$f" https://raw.githubusercontent.com/necronicle/d2k/main/scripts/install.sh && D2K_REF=main sh "$f"; r=$?; rm -f "$f"; exit "$r")
```

### Что делает установщик

1. Определяет архитектуру роутера.
2. Берёт последний выпуск: перечень выпуска с подписью и архив своей
   архитектуры.
3. Проверяет подпись перечня и контрольную сумму архива. Не сошлось —
   ничего не меняет.
4. Проверяет пакеты, модули ядра и свободное место.
5. Ставит D2K из проверенного архива.
6. Запускает службу.
7. Печатает адрес панели.

Ручная установка и ночное обновление ставят один и тот же подписанный
выпуск. Поэтому новая установка не бывает старее обновлённого роутера.

Код установщика: [scripts/install.sh](scripts/install.sh).

Выполните команду один раз. Потом D2K обновляет себя сам.

## Проверка после установки

1. Выполните команду:

   ```sh
   /opt/etc/init.d/S99d2k status
   ```

2. Проверьте строки «датапат: работает» и «контроллер: работает».
3. Откройте панель (см. раздел [Панель](#панель)).

D2K запускается в рабочем режиме (`MODE=apply`).

Первый обход для нового сайта появляется не сразу. D2K сначала измеряет
соединение и только потом ставит обход.

D2K не трогает трафик, который работает. Медленный сайт — это ещё не
блокировка.

**Если сеть работает плохо после установки,** выполните:

```sh
/opt/etc/init.d/S99d2k stop
```

Эта команда останавливает D2K и снимает его правила.

## Панель

Адрес панели: `http://<адрес-роутера>:8090/`.

Обычно это **http://192.168.1.1:8090/**. Точный адрес печатает установщик.

Панель показывает:

- состояние движка;
- текущие поиски обхода;
- найденные обходы;
- семейства доменов;
- Telegram-туннель;
- обновления.

**ВНИМАНИЕ:** У панели нет пароля. Не открывайте порт 8090 в интернет.

## Обновление

D2K обновляет себя сам.

1. Роутер проверяет новый выпуск ночью, между 03:00 и 05:00.
2. Роутер проверяет подпись выпуска. Если подпись неверна, роутер ничего не
   ставит.
3. Роутер сохраняет текущую версию.
4. Роутер ставит выпуск.
5. Через минуту роутер проверяет, что движок, контроллер и панель работают.
6. Если проверка не прошла, роутер возвращает прежнюю версию.

Кнопка «Установить сейчас» в разделе «Обновления» ставит выпуск сразу.

Тумблер в панели выключает ночную установку.

Обновление сохраняет настройки и подобранное.

Журнал обновлений: `/opt/d2k/log/update.log`.

## Управление

### Команды

| Команда | Что делает |
| --- | --- |
| `/opt/etc/init.d/S99d2k status` | показывает состояние |
| `/opt/etc/init.d/S99d2k stop` | останавливает D2K и снимает правила |
| `/opt/etc/init.d/S99d2k start` | запускает D2K |
| `/opt/etc/init.d/S99d2k restart` | перезапускает D2K |
| `/opt/etc/init.d/S99d2k clear-found` | стирает подобранное |

Настройки: `/opt/d2k/config`.

Журналы: `/opt/d2k/log/`.

### Стереть подобранное

**ВНИМАНИЕ:** Подобранное нельзя восстановить. После очистки D2K подбирает
каждый обход заново.

1. Откройте панель.
2. Нажмите «Очистить подобранное».
3. Прочитайте предупреждение.
4. Нажмите «Очистить».

Та же команда для SSH: `/opt/etc/init.d/S99d2k clear-found`.

Подобранное хранится в `/opt/d2k/state/`:

| Файл | Содержание |
| --- | --- |
| `catalog.json` | коробки и обходы TLS, QUIC и голоса |
| `http-plans.txt` | обходы открытого HTTP |
| `https-cache.txt` | проверки HTTPS для имён с подменой ответа |

Во время очистки движок останавливается. Потом он запускается снова.

## Удаление

**ВНИМАНИЕ:** Удаление стирает подобранное. Восстановить его нельзя.

### Keenetic

```sh
(f=$(mktemp) && curl -fsSL --connect-timeout 10 --max-time 120 https://raw.githubusercontent.com/necronicle/d2k/main/scripts/uninstall.sh -o "$f" && sh "$f"; r=$?; rm -f "$f"; exit "$r")
```

### OpenWrt

```sh
(f=$(mktemp) && wget -q -T 120 -O "$f" https://raw.githubusercontent.com/necronicle/d2k/main/scripts/uninstall.sh && sh "$f"; r=$?; rm -f "$f"; exit "$r")
```

### Что удаляет команда

- службы и панель D2K;
- правила D2K;
- DNS-записи D2K для Instagram и WhatsApp;
- настройки и подобранное;
- ключ Telegram.

Чужие правила и DNS-записи команда не удаляет.

На OpenWrt команда не удаляет пакеты. Другие программы могут их использовать.

### Сохранить настройки и подобранное

Добавьте `D2K_KEEP_STATE=1` перед `sh "$f"` в команде удаления.

Код удаления: [scripts/uninstall.sh](scripts/uninstall.sh).

## Instagram и WhatsApp

D2K сам ставит DNS-записи для Instagram и WhatsApp Web.

1. Роутер получает адреса от резолвера D2K на VPS.
2. Роутер проверяет, что адрес принадлежит Meta.
3. Роутер проверяет доступность адреса и его сертификат.
4. Роутер сохраняет 1–2 адреса на каждое имя.

Роутер обновляет записи каждый день, между 01:00 и 04:59. Каждая установка
выбирает свою минуту.

Если обновление не прошло, роутер повторяет его. Прежние записи остаются.

Каждый день роутер проверяет свои записи. Недоступную запись роутер снимает.

| Команда | Что делает |
| --- | --- |
| `/opt/d2k/d2k-instagram-dns.sh refresh` | обновляет записи сейчас |
| `cat /opt/d2k/state/instagram-ip-hosts.tsv` | показывает записи D2K |
| `tail -n 30 /opt/d2k/log/instagram-dns.log` | показывает журнал |

**ВНИМАНИЕ:** Не выключайте проверку сертификатов.

## Telegram

D2K включает Telegram-туннель сам.

Роутер создаёт свой ключ. Ключ не покидает роутер. Общий пароль не нужен.

Туннель ведёт только трафик Telegram. Остальной трафик идёт как обычно.

Если вы выключили туннель, обновление его не включает.

## Архитектуры

| Архитектура | Требования |
| --- | --- |
| ARM64 | AArch64 |
| ARM32 | ARMv7 и новее, little-endian, EABI, VFPv3 |
| MIPS / MIPSEL | MIPS32, big-endian или little-endian, soft-float |
| MIPS64EL | MIPS64, little-endian, N64 ABI, **нужен FPU** |
| x86 / x86-64 | i686 / x86-64 |
| PPC64 | 64-битный PowerPC, big-endian |
| RISC-V64 | RV64GC |

Каждый комплект собран статически. Библиотеки OpenSSL ставить не нужно.

D2K не работает на этих процессорах:

- Lexra;
- ARMv5 и ARMv6;
- 32-битный PowerPC;
- MIPS64EL без FPU.

Если архитектура неизвестна, установщик останавливается до любых изменений.

## Что проверено

### Проверено на роутере

ARM64-роутер Keenetic:

- 19 сайтов в Safari и Chrome;
- HTTP/3;
- WhatsApp Web;
- приложение Discord;
- IPv6 на телефоне Android.

### Проверено в лаборатории

- модульные тесты и кросс-сборка на 9 архитектур;
- запуск всех бинарников под QEMU;
- правила файрвола настоящим iptables;
- установка, обновление и удаление в изолированном контейнере;
- OpenWrt 24.10.8 и 25.12.5 в QEMU.

### Не проверено

- настоящий роутер с OpenWrt;
- модели, кроме ARM64 Keenetic;
- производительность на слабых роутерах.
