# 27.09.2026 — exact cleanup for name trials

`DEL_NAME` удалял все записи имени. При новом поиске это могло снести вместе с
временным кандидатом уже подтверждённый Plan той же цели. Это нарушало
изоляцию опыта и делало повторный поиск опасным.

Добавлена отдельная команда `DEL_NAME_PROBE` с ключом `(имя, форма, локальный
порт)`. Scheduler сохраняет форму и порт установленной пробы и использует
точное удаление для отмены кандидата и вопросов; подтверждённые `SET_NAME`
записи остаются. Проверено на таблице планов, управляющем сокете и полном
`test_sched`.

Это закрывает только изоляцию name-trial. Параллельные задачи, retry поколения,
таймауты и восстановление каталога после рестарта остаются отдельными пунктами.
