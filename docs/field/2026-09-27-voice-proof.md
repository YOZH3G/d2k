# 27.09.2026 — UDP voice protocol proof (local)

До этого voice arm ставился как временный `SET_NAME_PROBE`, а любой обратный
UDP-пакет был только наблюдением. Поэтому даже живой Discord поток никогда не
мог продвинуть кандидат в коробку.

Сделано локально:

- datapath запоминает SSRC клиентского Discord IP Discovery запроса;
- обратный пакет принимается как доказательство только при совпадении SSRC,
  строгой 74-байтовой сигнатуре, непустом ASCII-адресе и ненулевом порте;
- доказательство несёт отдельный `D2K_UDP_PROOF_VOICE_DISCOVERY` в уже имеющемся
  поле `EXCHANGE.code`, без смены версии wire-протокола;
- scheduler продвигает voice Plan в постоянный `SET_NAME` и каталог только по
  этому коду. Обычный, пустой, усечённый, мусорный или чужой ответ остаётся
  наблюдением.

Проверено: `make -C datapath check` (все тесты, включая wire-регрессию) и сборка
`make -C core test_sched`. Полевая проверка не выполнялась; роутер оставлен без
D2K по отдельному распоряжению.
