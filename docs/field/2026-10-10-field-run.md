## Находки

1. Классификатор не выразил TCP-блок: замер нашёл только «oob» (URG,
   планом не выражается), рабочий план — из перебора/RX-лестницы:
   фальшивый ClientHello ×8 с испорченным TCP timestamp + разрез +2
   (plan-680fbe00, wire tcp-template-v1). Вопрос о timestamp в замере есть,
   но этот план не дал; ответы отдельных TCP-вопросов в журнал не пишутся —
   почему, не проверено. Кандидаты для шага 6: oob в датапате (G3) и
   разбор, чем вопрос ts отличается от сработавшей фальшивки.
2. TX-объём ~15 КБ (dex.binance.org, cdn.imgchest.com, i121.fastpic.org,
   katzauction.b-cdn.net): «вердикта нет … 0 зондов», решает только перебор
   (~30 планов, 1,5–3,5 мин).
3. QUIC-поиски без кандидатов (63–72 зонда) повторяются раз в 10 мин для тех
   же имён (rutracker.org, fost.club, nnmclub.to, www.facebook.com).
4. Строки метрики: успех перебора не пишет «НАЙДЕН … (путь: перебор)»; у
   пути «прямой замер подтвердил блокировку» нет времени в строке; d2kc
   обрезает длинные строки журнала.
5. Автообновление: `d2k-update.sh run` читает AUTOUPDATE один раз при
   старте. `auto off` (и тумблер панели) без перезапуска цикла не выключает
   ночную установку. Здесь цикл перезапускался вручную. Не исправлялось.
